# Sommie

Brand and webinar platform for Sommie — forex trading, affiliate marketing and live mentorship.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Content

- Portrait: replace `public/sommie.jpg` (a warm-sand fallback shows if it is missing).
- Webinars, reviews and intro-video takeaways live in `src/components/data.ts`.
